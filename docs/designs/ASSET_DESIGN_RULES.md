# 에셋 제작 디자인 규칙

새 에셋을 만들거나 기존 에셋을 수정하기 전에 이 파일을 읽는다. 현재 적용할 기준만 담는다. 버전별 시안과 변경 이력은 `room/README.md`에 둔다.

## 작업 순서와 기준 화면

- 현재는 **밝은 세로 Home 방**의 가구·소품과 배치를 먼저 정한다. 어두운 버전은 밝은 버전이 정해진 뒤 마지막에 만든다. 가로 화면은 현재 범위에서 제외한다.
- 방은 벽과 바닥으로 구성하며 경계는 이미지 높이의 약 63%다. 스크래처처럼 바닥에 닿는 물체는 실제로 보이는 아래 끝을 경계에 맞춘다. 캣타워 등 높은 가구는 별도 레이어로 배치한다.
- 새 에셋은 배경·고양이·타이머·문구를 합쳐 넣지 않은 **독립적인 투명 레이어**로 만든다. 아크릴처럼 비치는 부분은 PNG/SVG에서도 실제로 투명해야 한다.

## 선과 표면

- **모든 신규·수정 에셋의 바깥선**은 기준 고양이 `cat/calico_cat_tail_up.png`의 선과 **최종 화면 표시 크기에서 같은 굵기**로 보이게 한다. 윗면과 앞면의 경계, 이음선, 박음질, 아크릴 테두리 등 **모든 내부선도 같은 표시 굵기**로 맞춘다.
- 원본 파일의 픽셀 굵기만 비교하지 않는다. 고양이와 에셋을 실제 배치 크기로 나란히 놓거나 겹친 미리보기에서 확인한다. 어두운 앞면 전체가 굵은 선처럼 보이는지도 확인한다.
- 선의 **색은 각 에셋의 재질과 팔레트**에 맞춘다. 고양이의 털색이나 품종별 선 색을 가구·소품에 복사하지 않는다.
- 새 가구·소품은 매끈한 무광 표면과 약한 질감만 사용한다. 큰 수채화 얼룩, 눈에 띄는 종이결, 과한 광택이나 흰 하이라이트를 넣지 않는다. 기존 고양이의 수채화 질감을 가구 스타일로 옮기지 않는다.

## 배치와 밝기 버전

- 고양이가 앉거나 착지하는 자리, 발·가구 접점, 가림 순서와 배치 기준점(anchor)을 실제 화면 크기에서 확인한다. 접점에는 짧고 부드러운 그림자만 둔다. 화면 비율에 따라 배경을 `cover`로 자르면 벽·바닥 경계 위치를 기기 화면에서 다시 확인한다.
- 같은 물체의 밝은/어두운 버전은 캔버스 크기, 실루엣, 물체 크기, 시점·원근, 투명 여백, anchor, 착지 자리(spot), 앞뒤 레이어 경계를 같게 만든다. 조명에 따른 명도·채도·그림자만 조정한다.
- 고양이 품종이나 포즈를 새로 만들 때는 이 공통 규칙과 해당 `cat/*-regeneration-guide.md`를 함께 확인한다.
