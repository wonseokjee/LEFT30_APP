## 모든 신규 에셋의 선 굵기 (필수)

2026-11-17 확정: **이제부터 새로 만들거나 수정하는 모든 에셋**(고양이, 가구, 소품 등)의 **바깥선은 기준 고양이 그림 `../cat/calico_cat_tail_up.png`의 선과 실제 화면 표시 크기에서 같은 굵기**로 보이게 만든다. 에셋 안에 그린 경계선·이음선·박음질 등도 바깥선과 같은 표시 굵기로 맞춘다. 원본 이미지의 픽셀 수치만 비교하지 말고, 최종 배치 크기로 고양이와 나란히 놓거나 겹친 미리보기에서 확인한다. 선 색은 고양이의 색을 복사하지 않고 각 에셋의 재질과 색상에 맞춘다.

## 가구·소품의 밝은/어두운 버전 규칙

2026-11-17 결정: 새 가구·소품은 선택된 단색 방에 맞춰 **큰 수채화 얼룩과 눈에 띄는 종이결 없이**, 매끈한 무광 표면과 아주 약한 표면 질감으로 만든다. 기존 고양이 그림의 수채화 질감을 새 가구·소품의 스타일 지시로 복사하지 않는다. 밝은 방의 가구·소품과 배치를 먼저 확정하고 어두운 버전은 마지막에 제작한다.

가구·소품에도 위의 **모든 신규 에셋 선 굵기 규칙**을 적용한다. 바깥선뿐 아니라 상판과 옆면의 경계선, 이음선, 박음질 등 선으로 그린 모든 부분을 확인한다. 표면은 낮은 질감의 무광 스타일을 유지한다. `cat-cushion-light-v4.png`는 바깥선만 조정하고 갈색을 적용한 비교본이므로 이 기준의 완성본으로 취급하지 않는다.

`cat-cushion-light-v5.png`는 모든 선을 쿠션 고유의 청회색 계열로 통일한 검토 시안이다. `preview-cushion-v5.html`에서 고양이와 실제 배치 크기로 비교한 뒤 선택한다.

2026-11-17 밝은 방 가구 초안: 낮은 스크래처 `scratch-board-light-v1.svg`(원본 이미지 `scratch-board-light-source-v1.png`의 바깥 빛 번짐을 SVG 투명도 필터로 제외), 단일 벽 발판 `wall-step-light-v1.png`, 두 단 캣타워 `cat-tower-light-v1.png`. `preview-light-furniture-set.html`에서 개별 에셋과 방 배치를 함께 확인한다. 크기·착지 지점은 아직 시안 단계다.

사용자 수정에 따른 다음 시안: 바닥형 대신 긴 벽 부착형 `wall-scratcher-light-v1.png`, 기존 `floating-shelf-light-mid-v1.png`의 좌우 길이만 줄인 `wall-step-light-v2.png`, 다섯 단으로 높인 `cat-tower-light-v2.png`. `preview-light-furniture-set-v2.html`에서 각각 방에 배치한 크기를 비교한다. 벽 스크래처의 세로 패널 형태는 [벽 부착형 사이잘 스크래처 사례](https://www.zooplus.com/shop/cats/scratching_posts/scratching_pads/scratching_boards/127289)를, 긴 캣타워의 다단 구조는 [PawHut의 230–260cm 5단 모델](https://www.aosom.co.uk/item/pawhut-floor-to-ceiling-cat-tree-for-indoor-cats-5-tier-kitty-tower-climbing-activity-center-scratching-post~1F56TU5EPL801.html)을 참고했다. 제품 외형을 그대로 복제하지 않고 방의 색·선 규칙에 맞춘 시안이다.

다음 수정 시안: `wall-scratcher-light-v2.png`는 사이잘의 반복 무늬를 대폭 줄였고, `wall-step-light-v3.png`는 긴 선반의 표시 길이 대비 약 35%로 줄였다. `cat-tower-light-v3.png`는 맨 위 발판을 목재 지지 링과 투명 아크릴 반구로 바꿨다. 투명 해먹의 구조는 [미아오 스트럭쳐의 목재발판+투명반구 사례](https://m.miao.co.kr/product/%EC%BA%A3%ED%83%80%EC%9B%8C-%ED%88%AC%EB%AA%85%ED%95%B4%EB%A8%B9/52/)를 참고했다. `preview-light-furniture-set-v3.html`에서 방 배치를 검토한다.

가구와 소품은 먼저 밝고 중립적인 조명에서 투명 에셋으로 만든 뒤, 같은 물체의 어두운 버전을 제작한다. 두 버전은 **캔버스 크기, 물체의 실루엣과 크기, 시점·원근, 화면 안 위치, 투명 여백, 배치 기준점(anchor), 고양이가 앉거나 착지하는 자리(spot), 앞/뒤 레이어 경계가 같아야 한다.** 바꿀 수 있는 것은 조명에 따른 명도·채도·그림자 표현뿐이다. 같은 좌표로 두 파일을 번갈아 띄웠을 때 물체와 고양이의 접점이 움직이면 수정한다.

특히 캣타워·해먹은 고양이가 실제로 닿는 발판과 가림 부분을 동일하게 유지한다. 품종이나 방 밝기가 달라져도 이동 경로와 착지 좌표를 다시 잡지 않도록 하는 기준이다. 현재 작업은 세로 화면에 한정한다.

`preview-portrait.html`을 브라우저로 열면 선택된 `room-dark-portrait-flat-v1.png` 위에 `calico_cat_tail_up_dark_v3.png`를 올려 볼 수 있다. 고양이 크기는 슬라이더로 조절한다. 이 HTML은 디자인 비교용이며 앱 UI 구현은 아니다.

선택된 단색 배경은 내장 `image_gen`으로 이전 수채화 v1을 편집했다. 고양이 원본을 스타일 참고로만 사용하고, 방의 구조·명도·중립색은 유지하면서 큰 수채화 얼룩과 강한 종이결을 줄였다. 완전한 벡터 단색이 되지 않도록 미세한 무광 질감만 남겼다. 2026-11-16 사용자가 단색 1단계를 선택했다.

단색 방 2단계는 내장 `image_gen`으로 `room-dark-portrait-flat-v1.png`에서 생성했다. 생성 지시: “구도·벽/바닥 경계·저질감 표면·색온도는 그대로 두고 주변광만 약 8–10% 낮춘다. 극적인 밤 전환이나 새로운 얼룩을 만들지 않는다.” 선택되지 않은 2단계와 이전 수채화 배경 v1은 비교 기록으로 보관한다.

방 배경 v2·v3은 비교 후 사용하지 않기로 결정해 프로젝트에서 삭제했다. 배경 선택은 v1이다.

눈 후보 `../cat/calico_cat_tail_up_eye_reflection_v1.png`는 내장 `image_gen`으로 원본 눈 안에만 따뜻한 반사광을 요청해 만든 **검토용 별도 파일**이다. 승인된 `calico_cat_tail_up.png`는 바꾸지 않았다. 이전 CSS 후광(`preview-eye-sparkle.png`)은 눈 밖으로 번져 채택하지 않는다. 새 후보는 전체 눈이 빛나는 느낌은 줄였지만 실제 표시 크기에서 효과가 약하므로 아직 확정하지 않는다.

2026-11-16 추가: 사용자가 원하는 빛은 홍채 자체가 아니라 **어두운 홍채 주변의 밝은 눈 영역**이다. 내장 `image_gen`으로 원본에서 `calico_cat_tail_up_dark_v1.png`를, 그 결과에서 몸을 더 어둡게 하고 눈 주변을 남긴 `calico_cat_tail_up_dark_v2.png`를 만들었다. 두 파일 모두 검토용이며 승인된 원본을 대체하지 않는다. 생성 지시의 핵심은 “몸·다리의 명도를 낮추고 주황/갈색 무늬는 남긴다. 갈색 홍채와 검은 동공은 어둡게 둔다. 눈 모양 내부에서 홍채를 둘러싼 옅은 아이보리 부분만 가장 밝게 유지한다. 눈 밖 후광·추가 점·광선은 없다”였다. 현재 브라우저 비교에는 v2를 사용한다. 생성 과정에서 원본의 선과 표정이 미세하게 달라질 수 있으므로 채택 전 원본과 나란히 확대 비교한다.

중간 색을 유지하려고 원본 위에 `calico_cat_tail_up_dark_v2.png`의 눈 부분을 겹친 `preview-mid-dark-eyes.png` 시안은 **기각**했다. 두 고양이 이미지의 눈 형태와 위치가 정확히 같지 않아 어색한 중복이 생겼다. 비교 페이지에서는 제거했다. 한 장짜리 `calico_cat_tail_up_mid_dark_v1.png`도 생성했지만 몸이 요청한 중간 색보다 밝아 사용하지 않았다. 중간 색과 밝은 눈을 결합하려면 한 장의 동일한 캐릭터 이미지 안에서 눈 영역만 편집해야 한다.

사용자 요청에 따라 내장 `image_gen`으로 `calico_cat_tail_up_dark_v3.png`를 한 장의 독립 에셋으로 제작했다. 승인 원본과 dark v2를 참조하고, 두 번째 수정에서 몸만 더 어둡게 하며 홍채 주변의 밝은 눈 영역을 유지하도록 지시했다. 브라우저 오른쪽 시안은 이 PNG를 `room-dark-portrait-v1.png` 위에 단순히 배치한 것이다. 몸의 명도는 가운데 필터 시안보다 어둡기 때문에 아직 최종 승인 대상으로 표시하지 않는다.

브라우저 캡처 `preview-portrait-screenshot.png`에서 기본 크기 43%로 확인했다. 어두운 배경은 흰 몸·발과 바닥의 경계가 분명하고 털색이 잘 드러난다. 밝은 배경은 흰 다리와 바닥이 가까운 명도로 보여 대비가 약하다. 현재 다크 UI에는 어두운 세로형을 우선 후보로 둔다. 다만 흰 타이머와 계획 막대가 실제로 올라간 화면은 아직 확인하지 않았다.

### 고양이와 방의 조명 맞추기

`preview-night-lighting.png`는 같은 방에서 원본 합성과 야간 조명 합성을 비교한 브라우저 캡처다. 원본 고양이는 흰 몸이 실내보다 훨씬 밝아 붙여 넣은 이미지처럼 보인다. 미리보기에서는 고양이 레이어에만 `brightness(.62) saturate(.8) contrast(.96) sepia(.08)`을 적용하고 발 아래 흐린 접지 그림자를 추가했다. 이 수치는 **시안용**이며 품종·포즈별 최종 값은 아니다.

최종 장면에서는 방과 고양이에 동일한 방향의 약한 주변광을 적용하고, 발·가구 접촉 지점에만 짧고 부드러운 그림자를 둔다. 고양이 원본 PNG는 건드리지 않는다. 각 품종의 털색만 다른 기본 자산을 유지하고, 방의 조명은 별도 렌더링 레이어 또는 공통 필터로 처리한다. 가구를 추가할 때도 같은 조명·그림자 규칙을 적용한다. 고양이 몸 전체에 균일한 검정 오버레이를 씌우는 것보다 밝기·채도·방향성·접지를 함께 맞추는 편이 자연스럽다.

## 과거 배경 생성 프롬프트 기록 (현재 가구·소품 스타일 지침 아님)

1. 밝은 세로: “비어 있는 고양이의 방. 벽·벽과 바닥의 이음새·넓은 바닥만, Calico 기준 그림의 어린이책 수채화 질감과 종이 결을 참조. 중립 색, 중앙과 아래쪽 빈 공간. 고양이·가구·소품·문구 없음.”
2. 어두운 세로: “밝은 세로 배경의 구도·경계·질감·크기를 유지하고 색과 명도만 차콜 다크 모드로 바꾼다. 흰 타이머의 가독성을 위해 중앙 벽은 어둡게, 여러 품종이 보이도록 바닥은 조금 밝게. 오브젝트 없음.”
3. 어두운 가로(보관용): “어두운 세로 방의 차콜 수채화·벽과 바닥 경계를 유지한 가로 구도. 늘이거나 회전하지 않고 넓은 빈 바닥을 새로 구성. 타이머와 별도 고양이·가구 레이어를 위한 여백. 오브젝트 없음.”
